# RealType

Een rustige, realistische typing test. Een woord wordt pas vastgelegd wanneer de eerste letter van het volgende woord wordt getypt, zodat je na een spatie nog met Backspace kunt corrigeren.

## Ontwikkelen

```bash
npm install
npm run dev
```

## Controleren

```bash
npm test
npm run build
```

De workflow in `.github/workflows/deploy.yml` publiceert `main` automatisch naar GitHub Pages.
